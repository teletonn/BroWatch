# Ребренд: BroWatch / BroMesh

> Статус: **готово, прошито**. Видимые имена — BroWatch (приложение) и BroMesh (сеть).
> Маскот остался Сквачи (Squachy), эстетика SquachWare — тоже.

## Что переименовано (видимое)

- Заставка: `BROWATCH`, подзаголовок «ГОВОРЯЩИЙ СКВАЧ».
- Меню и экраны: `BROMESH` / `БРОМЕШ` (пункт настроек, заголовки, туториал, инвайт, сквад-меню, фраза).
- Тосты и подсказки: `BROMESH > PHRASE`, «Включи TRANSMIT» и т.д.
- BLE-имя платы для обновления: `BroWatch-XXXX` (`src/ota_ble.cpp`).
- Файл лога на SD: `/browatch-<день>.log` (`src/sd_log.cpp`); старые
  `/squachwatch-*.log` тоже подбираются при wipe.
- Серийный баннер: `USER_SETUP_INFO` → `BroWatch / …` (все 6 борд).
- Текст про ESP32 в детекциях: «…and this BroWatch».
- README: заголовок, описание, пути (`BROMESH`), ссылка на форк; апстрим-ссылки
  (сайт, эмулятор, клон) оставлены как есть.

## Что НЕ переименовано (специально)

- Wire-протокол SquachMesh: магия `SQM1`, CID `0xFFFF`, соль `SquachWatch/msg/v1`,
  счётчики, виды кадров — иначе потеряем совместимость с оригинальными платами
  и чужими фразами. Комментарий в коде это фиксирует.
- Идентификаторы C++ (`squachmesh.cpp`, `SettingsRow::SQUACHMESH`, `SquachMesh::`),
  ключи NVS, имена файлов — переименовывать ради переименования не стали.
- OTA-домен `squachwatch.com` — реальный сервер обновлений и манифестов.
- `web-flasher/` — сайт-прошивальщик апстрима, артефакт деплоя; для форка нужен
  свой хостинг (отдельная задача).

## Проверка

- `grep -rn '"[^"]*Squach\(Watch\|Mesh\)[^"]*"' src/` — остались только соль,
  комментарии и невидимые пользователю места.
- Плата в эфире видна как `BroWatch-XXXX`.
