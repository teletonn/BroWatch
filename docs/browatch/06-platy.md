# Платы: что у нас есть и чем шить

> Инвентарь физических плат. Обновлять при появлении новой платы:
> модель, вариант тача, MAC, env, дата прошивки, результат проверки.

## Плата 1 — 2.8" CYD (основная)

- Модель: ESP32-2432S028R (Cheap Yellow Display 2.8", 320x240).
- Дисплей: **ILI9341** (партия со старым стеклом; вариант ST7789 — env `cyd` — даёт белый экран).
- Тач: резистивный XPT2046 на отдельной шине (штатный для 2.8").
- Env: **`cyd-ili9341`**. Baud консоли/монитора: 2000000.
- MAC: *не записан — считать при следующем подключении (`esptool read_mac`).*
- Статус: прошита RU-версией, плата отвечает `[lang] RU`, русский по умолчанию.

## Плата 2 — 2.4" Sunton ESP32-2432S024

- Модель: ESP32-2432S024, вариант **C (ёмкостный тач CST820 по I2C)**.
  Определено перебором 2026-09-21: сборка `rlphantom-r` залилась, но тач не отвечал;
  сборка `rlphantom` при загрузке пишет `Capacitive touch (CST816/820) detected`.
- Дисплей: ILI9341 240x320, те же пины SPI, что у 2.8". **Подсветка на GPIO27**
  (у 2.8" — GPIO21), поэтому сборки `cyd` / `cyd-ili9341` на этой плате дадут
  тёмный экран — **не шить**.
- Env: **`rlphantom`**. Baud консоли/монитора: 2000000.
- MAC: **88:13:bf:62:31:c0** (ESP32-D0WD-V3).
- Статус: прошита 2026-09-21 (`rlphantom`, SUCCESS за ~83 с), отвечает `[lang] RU`,
  чип тача детектится. Финальная проверка — тап по экрану вживую.

## Как прошивать (шпаргалка)

```bash
newgrp uucp <<'EOF'
pio run -e <ENV> -t upload --upload-port /dev/ttyUSB0
EOF
```

- `<ENV>` — `cyd-ili9341` для платы 1, `rlphantom` для платы 2.
- Проверка после прошивки: открыть порт на 2000000, дёрнуть DTR (плата перезагрузится),
  в boot-логе искать строку тача (`Capacitive touch … detected` /
  `RL Phantom (resistive) …` / `No capacitive touch found …`), затем команда
  `LANG` должна ответить `[lang] RU`.
- Белый экран на 2.8" = не тот драйвер: перешить `cyd` ↔ `cyd-ili9341`.
- Тёмный экран на 2.4" = залита сборка от 2.8" (чужая подсветка): перешить `rlphantom`.
- Тач не отвечает на 2.4": убедиться, что залит `rlphantom`, а не `rlphantom-r`
  (на плате 2 проверено: `-r` не работает).

## Если подключены обе платы сразу

- Порты: `/dev/ttyUSB0`, `/dev/ttyUSB1` (порядок не гарантирован).
- `by-id` не поможет различить: у обеих CH340 без серийника (`usb-1a86_USB_Serial`).
- Различать по MAC: `esptool.py --port /dev/ttyUSBx read_mac` и сверять с таблицей выше.
