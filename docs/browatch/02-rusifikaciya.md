# Русификация BroWatch (RU/EN)

> Статус: **готово, прошито, проверено на железе** (`cyd-ili9341`, плата отвечает `[lang] RU`).
> Решение: двуязычный режим, `Settings::lang` (NVS `lang`), **по умолчанию RU**.
> Переключатель: SYSTEM-страница → `LANGUAGE / ЯЗЫК`; Serial: `LANG RU|EN`.

## Как это устроено

- `Theme::tr(en, ru)` (`include/theme.h`, `src/theme.cpp`) — единая точка выбора языка.
  Весь перевод идёт через неё; EN-путь попиксельно не изменился (проверено скриншотами sim).
- `Theme::printRU / textWidthRU / wrapTextRU` — смешанная ASCII/кириллица печать.
  ASCII идёт обычным GLCD-путём, кириллица — своим рендерером `drawRuGlyph`
  (попиксельно, в стиле Bangers: одинаковые пиксели в эмуляторе и на железе,
  без зависимости от FreeFont).
- `RuText` (`include/ru_text.h`) — UTF-8-декодер, счёт глифов (не байтов), предикаты.
- Шрифт **RuCyr8** (`include/ru_font.h`): Liberation Sans **Bold 9px + суперсемплинг**,
  U+0401–U+0451, плотная 81 запись (~300 байт глифов). Генератор:
  `tools/ttf2gfx.py --codes 1025,1040-1103,1105 [--supersample N] [--thresh N]`.
- Базовая линия: `RU_YSHIFT = +6` в `drawRuGlyph` —Caps кириллицы стоят на той же
  линии, что GLCD (проверено рендером «ЯРКОСТЬ - + 75%»).
- Замер ширины — по чернилам (`ruInk`), т.к. глифы Л/Д шире advance и иначе
  правосторонний текст уползал под край.
- `LOAD_GFXFF` включён во всех бордах (нужен был на этапе FreeFont, оставлен про запас).
- `s_toastHead[32]/s_toastSub[48]`, `s_confirm[64]`, `s_detBuf[96]`, `oath[160]`,
  `s_statBuf[80]` — буферы расширены под 2-байтовую кириллицу.
- Шаблоны сообщений: эфир несёт **индекс**, `CANNED_RU[N]` — только отображение,
  поэтому RU-плата и EN-плата (и оригинал SquachWatch) понимают друг друга.
- Тесты: `test/lang_test`, `test/ru_text_test`, `test/canned_ru_test` (+ стабы
  `Theme::tr` в `bgretire/hunt/lang/security_test`); `make -C test` — 23/23.
- Эмулятор: `sim --lang 1` (`compose`, `clear --inbox N`, `roster`, `settings`…).

## Что переведено

- Кнопки и бары: `[ СКАН ] [ ЖУРНАЛ ] [ ЧАСЫ ] [ СТЕРЕТЬ ] [ НАЗАД ] [ ВВЕРХ ] [ ОК ]` и все кнопки экранов.
- Всё меню настроек: строки, значения (`ВКЛ/ВЫКЛ`, фоны, болтовня, свет, часы…), группы, подэкраны (экорежим, защита, светодиод, фильтр типов, игнор).
- Экран сообщений целиком: 48 шаблонов, вкладки, эмоции (35), FILL, хинты, статусы, подтверждение, туториал (7 карточек), фраза, инвайт, сквад-меню, отряд.
- Входящие по-русски: красный бабл, сквад-лист, деск-коробка.
- Болтовня Сквачи (~300 строк): idle, настроения, время суток/недели, скан/охота реакции, клятвы, детекции, pet-реакции, шоу-офф, майлстоуны, статистика, яйца-пасхалки.
- Тосты, PIN-экран, обновление (включая причины ошибок), сети, пароль, дневник, бинго, зона, дата (`ПН..ВС`, `ЯНВ..ДЕК`), деск (фокус, письма), журнал, алерт (СИГНАЛ, шкалы, НОЧЬЮ/ПЕРВЫЙ), охота, равскан, бут-скрин, анлок костюмов, нудж, вотч-алерт, калибровка цвета, системные свойства, детектор-диагностика заголовков — см. таблицу ниже по ключевым строкам; полный перечень — в коммитах `37fee5b`, `0cf8d39`.
- Веб (`web/` в этом репо, v0.2.0): интерфейс на русском + пикер тех же 50 шаблонов и 35 эмоций (паритет сверен скриптом с `meshwords.cpp`/`emote_script.cpp`).

## Сознательно осталось на английском

- Коды типов детекций (`FLOCK`, `AXON`…) — это коды, не слова.
- Слова кодовой фразы, буквы клавиатур, набираемый текст — эфирный алфавит только латинский (протокол).
- Имена сетей/MAC/версии/SSID — динамика.
- Имена костюмов, ники, названия палитр/зон — собственные имена.
- Экран диагностики — отладочный.
- Заголовки Bangers (`NEARBY`, `LOG`) — у Bangers нет кириллицы; главный «РЯДОМ» отрисован обычным шрифтом.
- OTA-домен `squachwatch.com` — реальный сервер обновлений.
- Консольные теги (`[meshtalk]`…) — для разработчиков.

## Как добавлять новые строки

```cpp
Theme::printRU(t, Theme::tr("English", "Русский"));   // печать
int w = Theme::textWidthRU(t, s);                     // замер для центрирования
Theme::wrapTextRU(t, s, maxW, lines, n);              // перенос
```

Правила: кириллица ≤ ~24 глифов на строку `lines[][48]` (48 байт); snprintf-буферы
считать в байтах (UTF-8 ×2); массивы-параллели проверять `static_assert` на счёт;
эфирные индексы/порядки не менять.
