# browatch-web (v0.2.0)

Веб-приложение + USB/Serial-шлюз для BroWatch. Порт по умолчанию **40400**
(переопределяется `BROWATCH_PORT`). Только стандартная библиотека Python —
без зависимостей для сервера; `pyserial` опционален и нужен лишь `gateway.py`.

## Запуск

```sh
python3 server.py              # http://127.0.0.1:40400
BROWATCH_PORT=40400 python3 server.py
python3 gateway.py --port /dev/ttyUSB0 --baud 2000000   # шлюз с платы
python3 gateway.py --port /dev/ttyUSB0 --baud 921600    # шлюз с ESP32-донгла (окружение esp32-dongle)
python3 gateway.py --demo                                 # демо-генератор без железа
python3 smoke.py                                          # дымовой тест HTTP-уровня (сам поднимает сервер на :40499)
```

Автозапуск на хосте (сервисы + udev): `tools/web-install.sh`
(подробности — `systemd/README.md`).

## Что умеет

- Мессенджер-чат: пузыри (свои справа), дневные разделители, непрочитанные + кнопка «↓ новые», автоскролл, пометки «в эфир»/«эфир».
- Отряд как на плате: «В эфире» (кого слышит плата прямо сейчас) и «Недавно были»; сами приходят и уходят — добавить вручную нельзя, только кнопка «Я тут» (heartbeat веба).
- Эмоции платы 1:1 (35 штук, 6 табов, RU-ярлыки) — входящие показываются с именем и анимацией маскота, исходящие уходят в mesh-эфир через плату.
- Шаблоны 1:1 (50 строк, 6 табов) + реакции 👍/👎 (canned 48/49 в эфир).
- Радар детекций с цветами типов + спектр-фон.
- Realtime: SSE `/api/stream` + incremental poll-fallback.
- Уведомления браузера, когда вкладка скрыта (сообщения, эмоции, детекции, плата) + тосты внутри страницы. Разрешение — тумблер в настройках (🎨).
- PWA: манифест + service worker (app-shell в кэше, API всегда из сети) — ставится на телефон/десктоп.
- Табы на телефоне (Чат / Отряд / Радар), на десктопе — три колонки сразу (Отряд | Чат | Радар).
- Фоновая анимация с платы на canvas + маскот Lil Guy 1:1 из прошивки в шапке.
- Веб → плата: текст (`→плата`), шаблон, эмоция (`POST /api/bridge/send` → очередь → `gateway.py` кладёт `[BW {...}]` в Serial → плата передаёт в mesh-эфир).

## Проверка связи с платой (мост)

1. Прошейте плату окружением с мостом (`cyd-ili9341`, `rlphantom`, `cyd`, `awok` — флаг `-DBW_BRIDGE=1` уже в `platformio.ini`).
2. `python3 server.py` → http://127.0.0.1:40400
3. `python3 gateway.py --port /dev/ttyUSB0 --baud 2000000` (на плате: разблокируйте PIN-экран, иначе мост молчит).
4. В вебе появятся: сама плата (`USB-XXXX`), её входящие mesh-сообщения, сквад рядом, детекции из журнала, эмоции.
5. Шаблон/текст/эмоция через плату уйдут в эфир (нужны фраза и TRANSMIT на плате) и сразу покажутся в чате с пометкой «в эфир».
